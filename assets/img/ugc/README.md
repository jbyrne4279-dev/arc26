# UGC poster frames (optional)

Optional still frames shown before each creator clip plays, named
`ugc-1.jpg` … `ugc-8.jpg` (portrait 9:16). If absent, the card shows a branded
placeholder background instead — so the section looks fine without them.

The clips themselves go in `assets/video/` as `ugc-1.mp4` … `ugc-8.mp4`.
